# Calculator

A simple calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Clear all input with `AC`
- Pi shortcut
- Factorial support
- Simple button-based interface

## Tech Stack

- HTML
- CSS
- JavaScript

## How It Works

- Button clicks are captured in JavaScript.
- The current expression is stored in a string.
- Pressing `=` evaluates the expression and shows the result.

## Run the Project

1. Open the `Calculator` folder.
2. Open `index.html` in your browser.
3. Click the buttons to perform calculations.
