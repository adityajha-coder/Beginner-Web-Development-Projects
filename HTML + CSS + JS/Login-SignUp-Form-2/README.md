# Login SignUp Form 2

An animated login and registration interface featuring frosted glass styling and smooth sliding form transitions.

## Preview

![Login SignUp Form 2 - Login View](public/login-form-2a.png)
![Login SignUp Form 2 - Registration View](public/login-form-2b.png)



## Features

- Sliding form transition between Login and Registration
- Frosted glass UI effect using CSS backdrop filter
- Neon accent highlights and glowing button states
- Responsive container for mobile devices

## Tech Stack

- HTML
- CSS
- JavaScript

## How It Works

- Clicking the register or login link toggles an active class on the parent wrapper.
- CSS transforms slide the form container horizontally when active.
