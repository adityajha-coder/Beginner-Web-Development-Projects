# Login SignUp Form 3

An animated sliding overlay authentication container featuring glassmorphism background design, floating shapes, and smooth panel transitions built with HTML, CSS, and JavaScript.

## Features

- Sliding overlay transition between Sign In and Sign Up panels
- Floating background shapes with gradient animations
- Social media sign in options
- Mobile responsive layout with panel toggle

## Tech Stack

- HTML
- CSS
- JavaScript

## How It Works

- JavaScript adds or removes the `right-panel-active` class on the main container.
- CSS flexbox and transform transitions slide the overlay and form panels horizontally.

## Run the Project

1. Open the `Login-SignUp-Form-3` folder.
2. Open `index.html` in your browser.
3. Click Sign Up or Sign In to slide between forms.
