# Search Bar

A simple animated search bar UI built with HTML and CSS.

## Features

- Compact search input
- Search icon button
- Clean animated design
- Minimal responsive layout

## Tech Stack

- HTML
- CSS

## How It Works

- The search box is styled to expand visually as an interactive UI component.
- It is a frontend design demo and does not include search logic.

## Run the Project

1. Open the `search-bar` folder.
2. Open `index.html` in your browser.
3. Try the search bar UI.
