# Login Form Glass

A stylish glassmorphism login form built with HTML and CSS.

## Features

- Glass-style login card
- Email and password inputs
- Remember me option
- Forgot password and register links
- Responsive centered layout

## Tech Stack

- HTML
- CSS

## How It Works

- The page uses a single login form inside a centered wrapper.
- Styling creates the glass effect and visual polish.
- No backend is connected; it is a frontend UI demo.

## Run the Project

1. Open the `login-form-glass` folder.
2. Open `index.html` in your browser.
3. View the login form UI.
